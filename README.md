# Campus Boss Pro

Plateforme étudiante front-end en HTML/CSS/JavaScript.

## Fonctionnalités
- Connexion/déconnexion locale
- Profil étudiant + filière
- Tableau de bord
- Méthodes d'étude
- Filières et matières
- Ajout de PDF (métadonnées locales)
- Quiz avec score et XP
- Progression et objectifs
- Planning/tâches
- Mode sombre
- Responsive mobile

## Important
La connexion est une démonstration locale : le mot de passe n'est pas sécurisé et les données sont stockées dans localStorage. Pour une vraie plateforme avec comptes, mots de passe sécurisés, stockage PDF partagé et synchronisation entre appareils, il faut connecter un backend/authentification et une base de données.

## Lancer
Ouvrir `index.html`.

## GitHub Pages
Déposer les 3 fichiers (`index.html`, `style.css`, `script.js`) dans un dépôt puis activer GitHub Pages.
